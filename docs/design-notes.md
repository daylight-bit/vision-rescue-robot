# 从图像坐标到动作

目标中心横坐标可以与画面中心比较：偏差较大时转向，进入中心区间时执行下一步。现有代码采用阈值分段控制，不能称为已经实现 PID。

纵坐标在固定相机姿态下可作为接近程度的经验判断，但不等于经过标定的距离。编码器记录车轮转动，也不自动排除打滑误差。

后续实验建议：固定目标位置记录中心坐标波动；重复靠近记录成功和失败样本；让目标暂时离开画面检查停机策略。实验尚未执行，不填写虚构成功率或提升百分比。

资料检索应先从 RDK 官方推理示例、ROS2 订阅教程和底盘接口说明开始，再逐项核对输入格式、类别编号与电机方向。学习方法可以公开，过去是否实际执行过这些步骤仍需个人记录佐证。
